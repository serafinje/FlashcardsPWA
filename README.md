# FlashcardsPWA
Aplicación para practicar palabras de un idioma

Quiero hacer una aplicación para móvil para uso personal.  No voy a publicarla.
Será una aplicación para practicar palabras de un idioma.
El funcionamiento será: 
- Necesito tener almacenada una lista de palabras (con el idioma al que pertenecen, la traducción, un número que será el de intentos, un flag de palabra recordada, y la fecha de aprendizaje)
- La aplicación buscará las palabras con el número mayor y preguntará la traducción. Si fallo, el número se incrementa. Si acierto, el número decrece. Si llega a 0, la palabra se da por recordada y se apunta la fecha.
- Cuando la fecha supere cierta antigüedad, la palabra se desmarca para que no aparezca como recordada y el programa vuelva a preguntarla.
